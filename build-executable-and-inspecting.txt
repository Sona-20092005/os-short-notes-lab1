
1. Preprocessing - Handles macro expansions, file inclusions, and conditional compilation.

gcc -E hello.c -o hello.i

2. Compilation - Converts preprocessed code to assembly language.

gcc -S hello.i -o hello.s

3. Assembly - Converts assembly language to machine code, producing object files.

gcc -c hello.s -o hello.o

(as hello.s -o hello.o)

4. Linking - Combines multiple object files, resolves symbols, and includes libraries to
produce a complete executable.

gcc hello.o -o hello
ld hello.o -o hello -lc -dynamic-linker /lib64/ld-linux-x86-64.so.2
